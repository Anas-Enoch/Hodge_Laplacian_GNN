# PDE-Constrained Hodge-Laplacian Framework

This repository contains the implementation of the framework described in:

**A PDE-Constrained Hodge–Laplacian Framework for Falsifiable Inference in Transport-Dominated Systems**

## Overview

This project introduces a mathematically grounded framework for:
- Transport phenotyping
- Conservation-residual diagnostics
- PDE-constrained inference on discrete geometries
- Hodge decomposition–based failure typing

The framework formalizes advection–diffusion as a null model of passive transport and evaluates mechanistic adequacy via integral conservation constraints.

## Structure

- `scripts/` – Code for figure generation and synthetic experiments  
- `figures/` – Generated figures (if tracked)  
- `requirements.txt` – Python dependencies  
- `run_all.sh` – Reproducibility script  

## Reproducibility

All figures can be regenerated from the scripts provided.  
Synthetic benchmarks and diagnostic mapping are included.
