# Hodge-Laplacian GNN — Operator-Based Transport Phenotyping for Spatial Transcriptomics

**Non-passive transport organization at tumor–immune interfaces revealed by operator-based analysis**  
Anas Enoch, MD · Mohammed VI University of Health Sciences (UM6SS), Casablanca

---

## Overview

This repository implements a four-layer geometric inference and falsification pipeline for spatial transcriptomics data. The central finding: tumor–immune interfaces in TNBC consistently exhibit rotational (coexact) transport structure that cannot be reproduced by any gradient-only passive transport model.

Applied to 43 Visium sections from 22 primary TNBC patients (GSE210616):
- Coexact enrichment > 1.0 at tumor–immune interfaces in **40/40 valid sections** (sign test *p* < 10⁻¹²)
- Coexact enrichment exceeds exact enrichment in **38/40 sections** (median differential 2.54; *p* < 10⁻⁹)
- Finding is consistent across all 22 patients and independent of race, chemotherapy, and survival

## Pipeline Architecture

The pipeline operates as four logical layers. Each has a distinct role; together they form a closed chain from geometric detection through algebraic interpretation.

| Layer | Component | Role | Output |
|-------|-----------|------|--------|
| 1 | Wedge flux + Hodge decomposition | **Geometric probe** | Exact / coexact / harmonic components |
| 2 | Region enrichment, interface vs. tumor | **Spatial localization** | Statistical validation |
| 3 | PDE-constrained Hodge–Laplacian GNN | **Operator-class falsification** | Null model collapse signal |
| 3 | Lie algebra + discrete advection operator | **Mechanistic interpretation** | Antisymmetric dynamics |

**Key interpretive sentence:** The PDE-constrained GNN defines the maximal projection of the interaction field onto the symmetric (gradient-generating) operator class S, while the Lie algebra decomposition identifies the coexact component as the geometric projection of antisymmetric, advection-like dynamics that cannot be generated by any gradient-only transport mechanism.

> The GNN is not a predictor of biology — it is the best possible passive transport explanation.  
> The Lie algebra is not optional theory — it supplies the mechanistic reading of what the GNN cannot reproduce.

## Running the Pipeline

Activate the virtual environment, then run steps 1–7 sequentially for each sample.

```bash
source .venv/bin/activate

SAMPLE=GSM_xxxx
SAMPLE_DIR=data/TNBC_GSE210616/${SAMPLE}

# Step 1 — Marker scoring
python -m scripts_tnbc.step1_tnbc_map \
  --sample_dir ${SAMPLE_DIR}

# Step 2 — Region annotation
python -m scripts_tnbc.step2_tnbc_regions \
  --sample_id ${SAMPLE} \
  --sample_dir ${SAMPLE_DIR} \
  --statsdir stats/CSV_GSM \
  --figdir visium_figures

# Step 3 — Spatial graph and incidence matrices
python -m scripts_tnbc.step3_tnbc_spatial_graph \
  --sample_id ${SAMPLE} \
  --sample_dir ${SAMPLE_DIR} \
  --statsdir stats/CSV_GSM

# Step 4 — Wedge flux construction
python -m scripts_tnbc.step4_tnbc_flux_proxies \
  --sample-id ${SAMPLE}

# Step 6 — Hodge decomposition
python -m scripts_tnbc.step6_tnbc_hodge_decomposition \
  --sample-id ${SAMPLE} \
  --flux-col flux_tumor_immune_region_interface_weighted

# Step 7 — Interface enrichment testing
python -m scripts_tnbc.step7_tnbc_region_enrichment \
  --sample-id ${SAMPLE} \
  --flux-col flux_tumor_immune_region_interface_weighted \
  --min-nodes-per-region 10
```

> **Note on Step 5:** An optional metabolic proxy step. Skip unless metabolic flux variants are needed.

## Step 19 — Biological Anchoring

Step 19 tests whether the proxy-derived coexact phenotype aligns with biological variation within interface nodes — over and above gross region composition. It uses the **proxy field node-level coexact energy** (Step 6 output), not the constrained GNN output, because the question concerns the proxy phenotype before falsification.

The script computes five statistics in sequence:

1. **Raw Spearman** — descriptive only; not reported as primary
2. **Region-demeaned Spearman** — primary nonparametric check; removes region-composition confound
3. **OLS with region covariate** — standardized β for effect size; interpret cautiously at large n
4. **Within-interface analysis** — interface-like nodes only; tests biological variation inside the active boundary zone
5. **FDR correction** — BH correction applied separately to global and subset analyses

## Exclusion Criterion

Samples are excluded from the enrichment analysis (Step 7) if either the `interface_like` or `tumor_enriched` annotated region contains fewer than **10 nodes** after labeling. This threshold is pre-specified prior to examining any enrichment statistics and reflects the minimum region size at which the permutation test produces a stable null distribution (null_std < 2.0 empirically across this cohort).

Excluded samples are retained for global Hodge statistics (Step 6) and reported in the supplementary table with note `low_sample_size`.

## Common Issues

| Symptom | Cause | Fix |
|---------|-------|-----|
| `FileNotFoundError` | Missing `.h5`, positions, image, or JSON | Verify all four files present in sample directory |
| `WARNING: B2 is None – falling back to Delaunay` | No face schema in `step3_faces.csv` | Normal — Delaunay fallback is correct; no action needed |
| `Variable names are not unique` (scanpy) | Duplicate gene IDs | Non-fatal; call `.var_names_make_unique()` in Step 1 if suppression needed |
| Step 7 `low_sample_size` | Interface or tumor region < 10 nodes | Sample excluded from enrichment; global stats still valid |
| Slow permutations | Default n=1000 | Reduce to `--n-perm 100` for testing; use `--seed 0` for reproducibility |
| `harmonic_suppressed = True` | E_harmonic / E_coexact < 10⁻⁶ | Correct behavior — harmonic p-value is set to NaN when harmonic energy is at floating-point noise level |

## Statistical Notes

**Permutation null (Step 7):** Region labels are shuffled (1000 permutations); the enrichment ratio is recomputed each time. Two-sided empirical p-value: `p = (count + 1) / (n_perm + 1)`.

**Harmonic suppression:** When the global harmonic energy satisfies E_harmonic / E_coexact < 10⁻⁶, the harmonic component is operating at numerical noise from the lsqr projection. Any nominal significance for `node_energy_harmonic` in that regime is an artifact; the p-value is suppressed and the note field is annotated accordingly.

**Aggregate fractions:** Region-level `agg_frac_*` values use `sum(E_component) / sum(E_exact + E_coexact + E_harmonic)` as denominator — not the omega-derived `node_energy_total`. This guarantees fractions are always in [0, 1] regardless of numerical leakage in the lsqr projection.
