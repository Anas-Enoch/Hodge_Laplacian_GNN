# Legacy Visium Pipeline

These scripts correspond to the early TNBC discovery pipeline used to generate the original Hodge/coexact enrichment outputs.

They are retained for provenance only.

The corrected manuscript v7 analysis uses:
- scripts_gse278936/ for external validation and corrected multilayer analyses
- scripts_tnbc_rebuild/ to convert TNBC legacy outputs into the modern validation schema

These legacy scripts should not be interpreted as the final corrected validation pipeline.
